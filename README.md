
# Password Manager - Group 3

Desktop password manager application developed as a group project for **Software Engineering (CPU5005)** at Bath Spa University.

The client asked for a simple desktop app, not browser-based, where a user can store passwords securely. The focus of the project is software engineering and project management.

## Project goals

- Let a user log in and log out of the app
- Store passwords in a desktop application
- Store passwords securely (master password and protected storage)
- Keep the scope small and agree any extra feature with the client first

## Ways of working

- **Branches:** `main` is the stable version. Each feature or fix is developed in its own branch and merged through a pull request.
- **Reviews:** every pull request is reviewed by another team member before it is merged.
- **Commits:** short, clear messages, for example `Add login screen`.
- **Tasks:** tracked with GitHub Issues / Projects.
- **Meetings:** a fixed weekly meeting, with minutes saved in the Teams channel Minutes.
- **Documents:** requirements, design, risk register and reports are stored in the Teams channel Documents.
